# doc/dogfood/ — field reports from the live installation

Dated reports from running captAInHook's own payloads on the maintainer's
real Claude Code sessions. Each report records what went live, the evidence
(trail events, timings, API state), observations/friction, and a watchlist.

**Lane rule:** these are *observations*, not decisions or mechanics — the
environment imposes → `platform.md`; we chose → ADR; the code does → flow
doc; **we saw it happen live → here**. Non-authoritative for behavior (the
code and tests are); authoritative for "this ran on real traffic on this
date." A field report that uncovers a defect or a decision graduates into an
issue/commit or an ADR — the report just cites it.

Reports are append-only history: don't retro-edit one, write the next.
